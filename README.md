# Gather & Grain — Restaurant Platform UI

A mobile-first restaurant website concept inspired by the two supplied reference videos.

## Phase 1 included
- Responsive landing page with motion and reduced-motion support
- Menu category filters and sample dish cards
- Interactive cart drawer with quantity controls and subtotal
- QR-inspired visual treatment
- Accessible labels, keyboard Escape handling, and mobile layouts

## Prototype boundary
This is **UI-only**. Menu items and prices are illustrative. The cart is client-side only. It does not send restaurant orders, create real QR table sessions, authenticate restaurant staff, store customer data, or accept payments.

## Next phases
1. Real QR table links and order creation API
2. Database schema and restaurant/branch/menu management
3. Authenticated owner and kitchen dashboard with role checks
4. Secure payment provider integration (server-side order totals, signed webhooks, idempotency, no card data stored)
5. End-to-end tests, security review, and verified Vercel deployment

## Local preview
Open `index.html` directly in a browser or serve the repository root with any static HTTP server.

External imagery and Google Fonts require an internet connection.
